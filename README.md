# 📖 Information
This mod fixes the hitreg between Superb Warfare and Valkyrien Skies 2. I'll (hopefully) be actively maintaining it and adding more bug fixes as the need arises.
Anyway, I'd recommend using the newest version of Superb with this. The newer versions seem to have added fixes which improve block destruction calculations against ships.
